== Reproduce locally

The TCK runs through a dedicated script at the repo root:

[source,bash]
----
cd knock
sdk env

# Smoke test (KnockTckSmokeTest only)
./run-official-tck-mp-health-4.0.sh

# Full official suite (28 tests)
./run-official-tck-mp-health-4.0.sh all

# A single test by name
./run-official-tck-mp-health-4.0.sh -Dtest=TestName
----

The runner can also be invoked directly (this is what the script does after installing the reactor):

[source,bash]
----
mvn -f knock-tck/pom.xml -Psmoke test          # smoke
mvn -f knock-tck/pom.xml -Ptck-official test   # full official suite
----

[NOTE]
====
The TCK runs on the classpath (not the module path) as a deliberate Java Modules workaround for Arquillian/ShrinkWrap. In 0.2.0, `knock-tck` is a regular reactor module; its `smoke` / `tck-official` Maven profiles select the suite, and its artefact is never published to Maven Central (`maven.deploy.skip` — the TCK harness is not a release artefact).
====
